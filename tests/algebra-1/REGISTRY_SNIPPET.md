Follows the authoritative scope doc
(`~/workspace/euclid-worksheet/CURRICULUM_SCOPE.md`, "Algebra I — Topics 1–9"):
**one entry per lesson row**, doc sequencing preserved (T2/T3 taught mixed),
TEKS codes are the doc's codes with the `A.` subject prefix per repo convention
(doc lists `5A` → entry uses `A.5A`).

- **Topic numbering:** doc Topics 1–9 → registry topics **101–109**
  (geometry already occupies 1–15; no collision).
- **Quiz/test rows** in the doc are assessment groupings, not generator entries —
  none are included, per instruction. The doc's split Topic 7 / Topic 8 tests
  therefore produce no entries.
- **"Coming soon" placeholder ids replaced:** none. Algebra 1 is a new topic
  group; every existing `underConstruction` placeholder
  (`ch1-1-points-lines`, `ch2-1-inductive-reasoning`, …) is untouched.
- **Mission extensions** (required by the original task brief, not doc lesson
  rows): `a1-1-7-absolute-value` (absolute value basics) and
  `a1-23-13-two-way-tables` (statistics basics). Both are marked below.
